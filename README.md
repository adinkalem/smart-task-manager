# Smart Task Manager

A simple desktop task manager built with C# WinForms on .NET.

## Features

- Add new tasks.
- Edit existing tasks.
- Mark tasks as completed.
- Delete tasks.
- Search tasks by title or description.
- View task statistics.
- Clean and simple desktop UI.

## How to Run

1. Open the project in Visual Studio 2022.
2. Restore the NuGet packages if needed.
3. Build the solution.
4. Run the application.

## Technologies Used

- C#
- WinForms
- .NET

## Project Goal

This project was created to practice building a simple desktop application with a clean user interface and basic task management functionality.
